Como usar

O fluxo segue a dependência entre as entidades — cada passo precisa do anterior:

  1. Cadastre um cliente. Ele é o tutor responsável pelo pet.
  2. Cadastre um pet vinculado a esse tutor. O peso define a faixa de preço.
  3. Crie um agendamento escolhendo o pet, o serviço e uma data futura.
  4. Conclua ou cancele o agendamento enquanto ele estiver com status AGENDADO.

Esta página consome a mesma API REST documentada no README. O preço nunca é calculado aqui: o navegador apenas exibe o valor devolvido pelo servidor.
